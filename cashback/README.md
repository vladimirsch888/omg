# Кэшбэк-кошелёк

Страница со всеми кэшбэками по картам: какой картой платить в каждой категории.

- `index.html` — страница (публикуется как Artifact на claude.ai).
- `data.js` — карты и категории. Обновляется по скриншотам из банковских приложений.

Вкладки:
- **По категориям** — категории по алфавиту, крупно лучшая карта и процент, ниже остальные карты.
  В конце — лучшая карта для покупок вне категорий (базовый кэшбэк).
- **По картам** — карты по алфавиту, у каждой её категории по алфавиту, отметка «ЛУЧШАЯ»,
  где эта карта выгоднее остальных.

Поиск понимает бытовые слова: «продукты», «бензин», «лекарства», «метро», «обед» и т. п.

Сверху переключатель месяцев: у каждой категории может быть `month` (например, `2026-10`).
По умолчанию открывается текущий месяц, закончившиеся акции (`until`) скрываются.
