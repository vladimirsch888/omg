# Торрент-качалка на VPS

qBittorrent на сервере с веб-интерфейсом, закрытым логином и паролем.
Вы загружаете `.torrent`-файл или magnet-ссылку и управляете закачками,
а когда скачивание заканчивается, получаете ссылку на файл и качаете его
на iPhone.

```
https://<домен>/        веб-интерфейс (VueTorrent, удобен с телефона)
https://<домен>/links   последние скачанные: название, размер, ссылка
https://<домен>/files/  все готовые файлы, прямые ссылки
```

Как это устроено:

- **qBittorrent-nox** работает как systemd-сервис от отдельного пользователя
  `qbt`, а его веб-интерфейс слушает только `127.0.0.1:8090`.
- **Nginx** проксирует веб-интерфейс, отдаёт готовые файлы и держит HTTPS
  (сертификат Let's Encrypt через certbot, продлевается автоматически).
  Файлы и страница `/links` закрыты тем же логином и паролем (HTTP Basic Auth).
- Недокачанное лежит в `/srv/torrent/incomplete`, и снаружи его не видно.
  Готовые файлы переезжают в `/srv/torrent/downloads`.
- Когда торрент докачан, qBittorrent запускает `/usr/local/bin/torrent-box-finished`.
  Скрипт добавляет ссылку на `/links` и, если настроено, шлёт её в Telegram.
- Файлы отдаются с поддержкой докачки (HTTP Range), поэтому видео можно
  смотреть прямо в Safari, не скачивая целиком.

Если на этом VPS уже работает учёт выручки из `deploy/bootstrap-vps.sh`,
ничего не сломается. Качалка ставится отдельным виртуальным хостом Nginx
со своим доменом и не трогает существующие сайты.

## Установка

Нужен VPS на Ubuntu 22.04 или 24.04 с открытыми портами 80, 443 и 6881.
Скопируйте скрипт на сервер и запустите его от root:

```bash
scp torrent-box/install.sh root@<IP>:/root/
ssh root@<IP>
bash install.sh
```

Скрипт спросит пароль. В конце он выведет адрес, например
`https://torrent.203-0-113-10.sslip.io/`.

**Домен.** Покупать его не обязательно. По умолчанию используется бесплатный
`torrent.<ваш-ip>.sslip.io`, который сам указывает на IP сервера, и на него
выпускается нормальный HTTPS-сертификат. Если у вас есть свой домен, сначала
создайте A-запись на IP сервера, потом запускайте:

```bash
DOMAIN=torrent.example.com LE_EMAIL=you@example.com bash install.sh
```

Все параметры (передаются переменными окружения):

| Переменная | Что это | По умолчанию |
|---|---|---|
| `DOMAIN` | адрес качалки | `torrent.<ip>.sslip.io` |
| `TORRENT_USER` | логин | `admin` |
| `TORRENT_PASS` | пароль | спросит (Enter сгенерирует) |
| `LE_EMAIL` | e-mail для писем Let's Encrypt | не указывается |
| `TG_BOT_TOKEN`, `TG_CHAT_ID` | уведомления в Telegram | выключены |
| `WEBUI` | `vuetorrent` или `classic` | `vuetorrent` |

Скрипт можно запускать повторно, например чтобы сменить домен, пароль или
включить Telegram. Скачанные файлы и список торрентов при этом не пропадают.
Если при повторном запуске нажать Enter вместо пароля, останется прежний.

## Как пользоваться с iPhone

1. Откройте в Safari `https://<домен>/` и войдите.
   Добавьте страницу на экран «Домой» (Поделиться → На экран «Домой»),
   чтобы открывать её как приложение.
2. Нажмите **+**. Можно выбрать `.torrent` из «Файлов» (туда попадают
   торренты, скачанные в Safari или присланные в Telegram) или вставить
   magnet-ссылку.
3. Когда закачка завершится, откройте `https://<домен>/links` или дождитесь
   сообщения в Telegram и нажмите на ссылку. Safari один раз спросит логин
   и пароль (их можно сохранить в «Паролях»), затем:
   - **видео в mp4/mov** откроется и будет проигрываться сразу;
   - **любой файл** можно сохранить: долгое нажатие на ссылку → «Загрузить
     связанный файл». Файл окажется в «Файлах» → «Загрузки»;
   - если торрент состоит из нескольких файлов, ссылка ведёт на папку,
     и каждый файл в ней качается отдельно.
   - **mkv/avi** Safari не проигрывает. Скачайте файл или откройте ссылку
     в VLC или Infuse (там есть «Открыть сетевой поток» или «Загрузить по URL»,
     логин и пароль можно вписать в адрес: `https://логин:пароль@домен/files/...`).

## Уведомления в Telegram (по желанию)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Напишите своему боту любое сообщение и откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Ваш chat id находится
   в поле `"chat":{"id":...}`.
3. Перезапустите установку с этими параметрами:

```bash
TG_BOT_TOKEN=123456:ABC... TG_CHAT_ID=123456789 bash install.sh
```

Когда торрент докачается, бот пришлёт название, размер и ссылку.

## Обслуживание

```bash
systemctl status qbittorrent-nox        # состояние
journalctl -u qbittorrent-nox -f        # логи
df -h /srv/torrent                      # сколько осталось места
```

- Удалять ненужное удобнее всего из веб-интерфейса: «Удалить» с галочкой
  «удалить файлы». Иначе вручную: `rm -rf /srv/torrent/downloads/...`.
- Обновить VueTorrent можно повторным запуском `install.sh`: он всегда
  скачивает последнюю версию.
- Пароль хранится только в виде хэша: PBKDF2 в конфиге qBittorrent
  и apr1 в `/etc/nginx/torrent-box.htpasswd`. После 5 неудачных попыток
  входа веб-интерфейс блокирует IP на час.

## Важно

- Скачивайте только то, на что у вас есть права. Многие хостинги запрещают
  торренты в условиях использования, поэтому прочитайте правила своего VPS.
  Раздача (сидирование) тоже идёт с IP сервера.
- Следите за диском. Когда место кончается, закачки встают с ошибкой.
